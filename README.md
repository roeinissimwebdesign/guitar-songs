# השירים שלי

אפליקציית טלפון לכל השירים שרועי יודע לנגן בגיטרה. נועדה לרגע אחד: הגיטרה ביד, הראש ריק, ואין לו מושג מה הוא יודע.

## מה יש בפנים

שלושה מסכים. הפתע, שמגריל שיר בלחיצה ומעדיף שירים שלא ניגן מזמן. השירים, רשימה מלאה עם חיפוש שעובד על עברית ואנגלית וסינון למועדפים או לשירים שיש להם אקורדים. סטים, רשימות שיר מסודרות לערב מסוים.

מסך הנגינה מציג אקורדים מעל המילים בכיוון הנכון לעברית, עם גלילה אוטומטית, שליטה בגודל הטקסט ובמהירות, וטרנספוזיציה חיה של כל האקורדים.

## הרצה מקומית

```bash
npm install
npm run dev
```

השרת עולה על http://localhost:5273 . כדי לפתוח בטלפון שמחובר לאותו וויפיי, השתמש בכתובת ה-Network שוויט מדפיס.

## נתונים

הכל נשמר קודם מקומית ב-localStorage, כך שהאפליקציה נפתחת מיד ועובדת בלי רשת. ברקע יש מראה ב-Supabase, בטבלאות `guitar_songs` ו-`guitar_sets` שבפרויקט `jwcnrkziivefiptrohgj`. שינוי שנעשה בלי רשת נשמר בתור ונדחף כשהחיבור חוזר.

חשוב לדעת, הטבלאות פתוחות למפתח הציבורי שנמצא בקוד הלקוח, בלי התחברות. זו החלטה מודעת לגרסה הראשונה כי מדובר בשמות שירים, ואפשר להחליף אותה בהתחברות אמיתית מאוחר יותר. בהגדרות יש ייצוא ושחזור של קובץ גיבוי.

משתני הסביבה יושבים ב-`.env`, ראה `.env.example`.

## אייקונים

`public/icon.svg` הוא המקור. אחרי שינוי שלו יש להריץ `npm run icons` כדי לייצר מחדש את קובצי ה-PNG שהאייפון צריך למסך הבית.
